# Aruna

> Tanya dulu, datang dengan berkas lengkap.

Portal Edukasi Layanan Disdukcapil Kota Semarang

Portal edukasi berbasis AI (RAG) untuk layanan administrasi kependudukan. Hanya sosialisasi dan edukasi,
bukan kanal pengajuan resmi.

## Mulai

```bash
pnpm install
cp .env.example .env.local   # isi nilai; jangan commit
pnpm dev
```

Perintah lain: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e`, `pnpm build`.
`pnpm eval:rag` sengaja gagal sampai runner evaluasi diimplementasikan.
